# Agency AI CRM SaaS for WordPress

Professional WordPress plugin scaffold for a multi-tenant AI-powered agency CRM. It includes activation-time MySQL schema creation, REST endpoints, admin CRM screens, a client portal shortcode, lead scoring and verification, automation hooks, document payload services, and integration placeholders for WhatsApp Cloud API, Meta Ads, Google Ads, Google Calendar, Zoom/Meet, Razorpay, Cashfree, Stripe, and PayPal.

## Install

Upload this folder to `wp-content/plugins/agency-ai-crm`, activate **Agency AI CRM SaaS**, then open **AI CRM** in WordPress Admin.

## Shortcode

Use `[agency_ai_crm_portal]` on a page to expose the client portal.
